# Código de conduta

Esperamos colaboração respeitosa, técnica e objetiva.

Não são aceitos assédio, discriminação, ataques pessoais, exposição de dados
privados ou pressão para executar mudanças inseguras.

Discussões devem se concentrar no comportamento do software, evidências,
reprodução do erro e segurança da correção. Mantenedores podem editar ou
remover conteúdo que viole estas regras.
